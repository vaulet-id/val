# สิ่งที่คุณกำลังสร้าง

Micro App รันอยู่ใน wallet ของผู้ใช้ ข้างพาสปอร์ตและ credential ธนาคารของเขา
มันอ่าน credential ที่เขาถืออยู่แล้ว คำนวณ แล้วขอให้ wallet ลงมือทำ

คุณไม่ได้ deploy มันขึ้นเซิร์ฟเวอร์ของคุณเอง คุณเผยแพร่ package ที่ถูกเซ็น
ผู้ใช้ติดตั้ง แล้วมันรันบนเครื่องของเขา

## สิ่งที่คุณได้

**ไม่ต้องสร้างระบบ login** ผู้ใช้ถูกระบุตัวตนแล้วด้วย credential ที่รัฐ ธนาคาร
โบรกเกอร์ที่มีใบอนุญาต หรือนายจ้างออกให้ คุณขอ claim แล้วได้ claim ที่ตรวจแล้ว

**ไม่ต้องเก็บข้อมูลผู้ใช้** ข้อมูลอยู่ใน wallet ของเขา คุณอ่านมันภายใต้ policy
ที่คุณระบุชื่อไว้ ใช้งาน แล้วมันก็ไม่กลายเป็นแถวในฐานข้อมูลของคุณ

**พิสูจน์ได้โดยไม่ต้องเปิดเผย** คุณให้คำถาม "คนนี้อายุเกินยี่สิบไหม" ถูกตอบได้
โดยไม่ต้องรู้วันเกิด

**record ที่ถูกเซ็นของทุกการรัน** แต่ละ action ผลิต record: โค้ดชุดนี้ เวอร์ชันนี้
state ก่อนหน้า state หลังจากนั้น เมื่อลูกค้าโต้แย้งธุรกรรม นั่นคือสิ่งที่คุณมี
แทน log file ที่คุณเขียนเอง

## สิ่งที่คุณต้องยอมเสีย

**คุณไม่ได้วาดหน้าจอ** คุณประกาศ `card` `row` `button` แล้ว wallet ตัดสินว่ามัน
หน้าตาเป็นอย่างไร ทุกแอปบนแพลตฟอร์มจึงดูเหมือนเป็นส่วนหนึ่งของที่นั่น

**คุณไม่ได้ถือ credential** คุณได้คำตอบของคำถามที่คุณถาม ไม่ใช่สำเนาของเอกสาร

**คุณทำสิ่งที่ไม่ได้ประกาศไม่ได้** capability ถูกตรวจก่อนโค้ดคุณจะรัน และการ
ประกาศสิ่งที่ไม่เคยใช้ทำให้ build ล้มเหลว

**บางอย่างไม่มีในภาษานี้** ไม่มี floating point ไม่มี recursion ไม่มีลูปที่ไม่รู้จุดจบ
ไม่มีการประกอบ string ดู[เอกสารอ้างอิง](../../th/spec.md)

## VAL หรือ webview

คุณจะส่งเป็น webview ก็ได้: HTML และ JavaScript ของคุณเองในเฟรม คุยกับ wallet
ผ่าน bridge เป็นทางที่เร็วกว่าถ้าคุณมีทีมเว็บอยู่แล้ว

| | webview | VAL |
| --- | --- | --- |
| วาดหน้าจอเอง | ได้ | ไม่ได้ |
| อ่าน credential ผ่านชีตของ wallet | ได้ | ได้ |
| ออก credential | ไม่ได้ | ได้ |
| รับชำระเงิน | ไม่ได้ | ได้ |
| เซ็นสิ่งที่ผู้ใช้อนุมัติ | ไม่ได้ | ได้ |

wallet พูดไม่ได้ว่า webview ของคุณทำอะไรลงไป มันจึงเสนอ capability ที่ต้องอาศัย
การพูดแบบนั้นให้ไม่ได้ ถ้าคุณต้องการ capability เหล่านั้น ให้ใช้ VAL

## package ประกอบด้วยอะไร

```
loyalty.val      ตัวแอป: capability, credential, action
wallet.val       หน้าจอหนึ่งหน้า อยู่ใน package เดียวกัน
text.json        ทุกประโยคที่ผู้ใช้จะได้อ่าน ในทุกภาษา
```

คุณคอมไพล์ เซ็น แล้วส่งมอบไฟล์ `.va` wallet ตรวจทั้งหมดใหม่ตั้งแต่ต้น —
การที่ build ของคุณผ่านไม่ได้พิสูจน์อะไรเกี่ยวกับ package ของคุณ
