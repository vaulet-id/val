# หน้าจอ

คุณประกาศหน้าจอ host เป็นคนวาด

```val
screen Wallet {
  data {
    receipts: credentials of PurchaseReceipt verified with ReceiptFromMerchant
      order by purchased_at desc
      limit 50
  }

  column {
    card(text: "balance", points: state.member.points)
    section(text: "history")
    list(receipts) { r ->
      row(text: "receiptLine", merchant: r.claims.merchant, at: r.claims.purchased_at)
    }
    button(text: "scan", emphasis: primary, onTap: ScanToEarn)
  }
}
```

## ประกาศข้อมูลที่ต้องใช้ อย่าไปดึงเอง

บล็อก `data` ถูก resolve โดย host **ก่อนที่จะมีการวาดอะไรทั้งสิ้น** ไม่มีหน้าจอ
ที่วาดค้างครึ่งเดียว ไม่มีกล่องขออนุญาตโผล่มาตอนที่ใครกำลังเลื่อนอ่าน และมีบล็อก
เดียวที่ผู้ตรวจอ่านแล้วรู้ว่าหน้าจอนี้เห็นอะไรใน wallet บ้าง

`verified with` ทำงานจริง: list แสดงใบเสร็จที่ไม่ผ่าน policy ไม่ได้ ไม่ใช่
"ถูกกรองออก" แต่คือปรากฏไม่ได้ เพราะการกรองเป็นของ host ไม่ใช่บรรทัดในโค้ดคุณ
ที่ใครสักคนลบทิ้งได้

`limit` ไม่ใช่ความสุภาพ มันคือสิ่งที่ทำให้ผลรวมของ list เป็นการคำนวณที่มีขอบเขต
และเป็นสิ่งที่ทำให้ proof เหนือมันคอมไพล์ลงไปเป็นวงจรได้

## การกดคือการระบุชื่อ action

`onTap` ระบุชื่อ action ที่คุณประกาศไว้ ไม่มี handler ชนิดอื่น ทุกอย่างที่หน้าจอ
เริ่มได้จึงผ่าน `require → verify → compute → update → execute` ด้วยความยินยอม
ชุดเดียวกันและ record ชุดเดียวกัน **หน้าจอไม่ได้เพิ่มเส้นทางไปหา effect เลย**

## component เป็นของ host

คุณได้เท่าที่ host ส่งมาให้ บน Vaulet วันนี้คือชุดเล็กๆ — card, row, section,
list, button — และการขออย่างอื่นไม่ได้ทำให้วาดอะไรที่ใกล้เคียงออกมา แต่บอกว่า
component นั้นไม่มีในแคตตาล็อกนี้

prop เป็น **เชิงความหมาย**: `text` `icon` `emphasis` `state` `onTap` ไม่มีสี
ไม่มีฟอนต์ ไม่มีขนาดพิกเซล ทุกแอปจึงดูเหมือนเป็นส่วนหนึ่งของ wallet ซึ่งเป็นข้อดี
สำหรับผู้ใช้และเป็นข้อจำกัดสำหรับคุณ ถ้าคุณต้องการพิกเซล คุณต้องการชั้น webview
— พร้อมเพดาน capability ที่ต่ำกว่า

package ของคุณบันทึกไว้ว่ามันถูก build กับแคตตาล็อกเวอร์ชันไหน และ host ก็เรนเดอร์
ความหมายชุดนั้นหรือไม่ก็ปฏิเสธ component ที่เงียบๆ แล้วเปลี่ยนความหมายในเวอร์ชัน
ถัดไปคือหน้าจอที่ผู้ใช้ไม่ได้ให้ความยินยอมไว้

## ข้อความไม่ได้อยู่ในโค้ดคุณ

`text: "balance"` เป็น key ที่ชี้เข้าไปใน bundle ที่ถูกเซ็นของคุณ ไม่ใช่ประโยค:

```json
"balance": { "en": "You have {points} points", "th": "คุณมี {points} แต้ม" }
```

คุณให้ค่าใส่ช่อง host จัดรูปแบบให้ นั่นไม่ใช่การแบ่งเพื่อจะแบ่ง — มันแปลว่า
เลขไทย พุทธศักราช และตำแหน่งสัญลักษณ์สกุลเงินถูกต้องครั้งเดียวสำหรับทุกแอป
แทนที่จะผิดกันคนละแบบในสี่สิบแอป

VAL ประกอบ string ไม่ได้เลย ไม่มี interpolation ไม่มี `+` ทุกประโยคที่ผู้ใช้อ่าน
มาจากสิ่งที่ถูกเซ็นมาแล้ว ซึ่งก็เป็นสิ่งที่ทำให้กฎห้ามเลียนแบบหน้าตาของ wallet
บังคับใช้ได้จริง

## state ของการโต้ตอบไม่ใช่ state ของคุณ

แท็บไหนเปิดอยู่ list เลื่อนไปถึงไหน อะไรถูกพิมพ์ในช่องที่ยังไม่ได้ส่ง: เป็นของ
host ทั้งหมด `state` ของคุณถูกแฮช ถูกเซ็น และถูก replay — ตำแหน่งการเลื่อนที่อยู่
ในนั้นจะเจือจางคำว่า "พิสูจน์ได้" ลงทุกครั้งที่มีคนกด

คุณได้สิ่งที่ฟอร์มถืออยู่ **ณ วินาทีที่มันถูกส่ง** ผ่าน `input`

## หน้าจอคำนวณต่อยอดได้ แต่ลงมือทำไม่ได้

```val
compute {
  const totalValue = holdings.fold(0) { sum, h -> sum + h.claims.market_value }
}
```

pure ใช้กติกาเดียวกับ action ไม่มี effect การเก็บผลรวมไว้ใน `state` แทนจะเป็น
การแฮช เซ็น และ replay ตัวเลขที่เป็นฟังก์ชันของสิ่งที่อยู่บนหน้าจออยู่แล้ว —
ซึ่งเป็นวิธีที่ตัวเลขหนึ่งตัวสองสำเนาเริ่มไม่ตรงกัน
