# Capability กับความยินยอม

ทุกอย่างที่แอปของคุณทำได้อยู่ในบล็อกเดียว และมีคนตกลงกับบล็อกนั้นก่อนที่มันจะรัน

```val
capabilities {
  credential.read(PurchaseReceipt)
  credential.issue(LoyaltyMember)
  disclosure.present
  api.query(audience: "broker.co.th", presenting: BrokerageAccount)
}
```

## มันระบุ type ไม่ใช่ string

`credential.read(PurchaseReceipt)` ถูกตรวจ ถ้าเป็น string มันจะกลายเป็นสำเนา
ที่สองของชื่อ และคนที่เจอการพิมพ์ผิดครั้งแรกจะเป็นลูกค้า

และมันคือสิทธิ์ทั้งหมด: การอ่าน `PurchaseReceipt` ไม่ได้ทำให้คุณอ่านพาสปอร์ตได้
ประกาศ type หนึ่งแล้วไปอ่านอีก type หนึ่งจะคอมไพล์ไม่ผ่าน และ error บอกว่าเพราะ
อะไร — มันไม่ใช่สิทธิ์ที่น้อยลง แต่เป็นสิทธิ์คนละอันที่ติดป้ายถูกต้อง

## หนึ่งบล็อก หนึ่ง package

package หนึ่งมีได้หลายไฟล์และใช้ scope ร่วมกัน แต่ capability ถูกประกาศครั้งเดียว
ผู้ใช้ยินยอมกับรายการหนึ่งรายการ ไม่ใช่ผลรวมของรายการจากทุกไฟล์ของคุณ และคำถามว่า
"ไฟล์ไหนบอกว่าแอปนี้ทำอะไรได้" ต้องมีคำตอบเดียว

## ประกาศแล้วไม่ใช้ = ล้มเหลว

ประกาศสิ่งที่ไม่เคยใช้แล้ว build ล้มเหลว นี่คือกฎที่คนคัดค้านมากที่สุดและเป็นกฎที่
ควรเก็บไว้ที่สุด: แอปที่ขอมากกว่าที่ต้องการ ฝึกให้ผู้ใช้เลิกอ่าน แล้วแอปตัวถัดไป
ก็คือตัวที่ควรจับตาจริงๆ

## สิ่งที่ผู้ใช้เห็นจริงๆ

ไม่ใช่บล็อกนี้ เขาเห็น **รายงาน capability** ซึ่งคอมไพเลอร์อนุมานจากโค้ดของคุณ:

```
reads          PurchaseReceipt.amount, PurchaseReceipt.purchased_at
               under ReceiptFromMerchant
discloses      NationalId.country
proves         birthdate <= now - 20 years
issues         LoyaltyMember
talks to       broker.co.th
writes state   member.points
irreversible   one disclosure
```

claim ที่คุณแตะ ไม่ใช่แค่ตัว credential ของอะไรไปไหนบ้าง และมีอะไรเกิดขึ้นที่
เอาคืนไม่ได้หรือเปล่า

คุณพูดให้น้อยกว่าความจริงไม่ได้ host คำนวณรายงานใหม่จาก source ของคุณ และปฏิเสธ
package ถ้ามันไม่ตรงกับที่คุณส่งมา — เพราะคู่ต่อสู้ที่น่าสนใจไม่ใช่คนที่ดักแก้
package ระหว่างทาง แต่เป็นผู้เผยแพร่ที่เซ็นรายงานที่เข้าข้างแอปตัวเอง

ซึ่งก็เป็นเหตุผลว่าทำไม **source เดินทางไปพร้อม package** แฮชของผลลัพธ์ที่คอมไพล์
แล้วพิสูจน์ได้ว่ามันคือผลลัพธ์ที่ใครบางคนเซ็น แต่ไม่เคยพิสูจน์ว่ามันคือโปรแกรมที่
ใครบางคนอ่าน
